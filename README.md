# 搬瓦工官网入口与 VPS 选购指南

搬瓦工（BandwagonHost）是 IT7 Networks 旗下的 VPS 服务商。VPS 可以理解为由服务商提供、需要用户自行管理的虚拟服务器：选定套餐并开通后，用户可以选择系统，在服务器上学习 Linux、部署网站或运行自己的服务。它与开箱即用的网站托管不同，系统维护、账户安全和数据备份都需要使用者关注。

本文整理官网入口、六种套餐的参考价格与购买步骤，帮助初次接触 VPS 的读者先弄清楚自己要买什么，再到订单页面核对实际条件。价格、库存、机房和优惠可能发生变化，表格不能替代提交订单前的确认。

## 套餐怎么选：从用途倒推需求

### 学习 Linux 或初次接触服务器

先考虑自己需要运行什么，再估算可接受的支出。如果主要是熟悉系统、命令行和服务器管理，可以先查看普通 KVM A 的资源及年付金额。年付意味着需要一次承担整个周期的费用，比较时不要只看折算后的月均金额。若还不确定长期用途，也要把付款周期和可能的续费成本一起考虑进去。

初学者除了比较价格，还要确认自己愿意负责哪些管理工作。选择 VPS 后，安装和维护应用、保管登录凭据、检查资源使用情况都需要自己处理；如果没有时间学习这些操作，先了解控制面板及基本管理流程会比急着下单更有帮助。

### 建站或部署长期运行的服务

网站的图片、文件下载和访问量都会影响流量需求。可以先依据现有业务估计用量，再对照表中的每月额度；如果已有网站，迁移前也应检查程序所需的系统、存储空间和其他资源。流量不是唯一指标，订单页面的配置、计费周期和机房同样需要逐项核对。

需要比较不同机房或线路时，可以从 [CN2 GIA-E A 方案](https://bwh81.net/aff.php?aff=85082&pid=87) 开始查看，再与 B 的流量及价格对照。如果主要访问者集中在某一地区，选择前应关注该地区与可选机房之间的实际网络情况，而不是把线路名称当作速度保证。

### 更关注香港机房或较大的流量额度

香港 A 和 B 的选择重点是 500GB 与 1TB 的月流量差异，以及对应的月付、年付支出。先判断业务是否确实需要香港机房，再考虑更大的流量档位；如果流量预计超过所选额度，还应在购买前查明超额如何处理。对于其他系列，也可以按同样方法比较 1TB 与 2TB，而不必仅因为档位更高就购买。

## 搬瓦工购买教程：从注册到确认订单

1. **进入官网并查看方案。** 使用上面的官网入口浏览套餐，或者通过对比表进入具体方案。注意核对页面显示的方案名称，避免把普通 KVM、CN2 GIA-E 和香港方案混淆。没有确定方案时，先查看全部套餐和库存更方便比较。
2. **注册账户。** 在网站注册页面填写邮箱、密码及要求的个人信息。使用能够接收邮件的邮箱，并妥善保存登录凭据；姓名、地址等信息应按实际情况填写，以便后续处理订单和账户事务。已有账户则先登录，避免无意中建立多个账户。
3. **选择套餐与付款周期。** 进入方案页面后检查价格、流量和资源，再查看可选的月付、季付、半年付或年付周期。并非每个套餐都有相同周期；实际选项以页面显示为准。切换周期后，重新核对订单金额和下一次续费涉及的条件。
4. **核对机房。** 查看订单中允许选择的机房，结合目标访问地区和用途做选择。参考资料中的机房列表不等同于实时库存；如果希望日后迁移，购买前还应查看当前方案的迁移条件，而不是假设任何机房都能随时更换。
5. **尝试输入优惠码。** 参考资料列出搬瓦工优惠码 `BWHCGLUKKB`，并称其为约 6.77% 的循环折扣。在结算页输入后，检查页面是否接受、折扣金额和适用条件；有效性及是否适用于当前订单可能变化，不要在未验证前把优惠计入预算。
6. **选择付款方式并复核。** 参考资料提到支付宝、PayPal、信用卡和银联；具体可用方式以结算页面为准。如果希望支付宝付款，先确认页面提供相应选项。提交前再次检查方案、周期、机房、金额、优惠结果和账户信息。
7. **完成支付并查看邮件。** 支付后留意账户状态和欢迎邮件，核对服务信息；如果没有立即看到开通信息，先检查邮箱及账户内的订单状态。不要把邮件中可能包含的敏感信息转发给无关人员。

## 开通后：先确认服务，再开始部署

收到欢迎邮件后，先把订单中的方案、机房和服务信息与预期逐项对照，并确认能够登录账户及 KiwiVM 控制面板。账户密码、服务器登录信息等应妥善保管；如果发现信息不符或无法访问，保留订单相关记录，再通过服务商提供的渠道咨询。

接着查看系统与资源。参考资料提到多种 Linux 系统可供选择；准备安装网站程序或其他应用时，应先确认其系统要求，避免部署到不兼容的环境。重装或更换系统前，先弄清操作对现有数据的影响，已有重要文件时尤其要先做好备份。

流量和数据保护也应从一开始就纳入管理。定期在控制面板查看流量使用情况，对照套餐每月额度，了解业务的实际消耗。参考资料提到快照和自动备份，但备份的具体条件、保留方式及恢复范围应在服务页面核实；重要数据最好另有可用的备份，并事先了解如何恢复，不能把一次开通视为后续数据安全的保证。

## 购买前常见疑问

**官网打不开，是否需要重新注册？** 不必因为一个入口暂时无法访问就重新注册。先检查地址和网络，再尝试资料列出的其他镜像域名；资料称账号和服务互通。实际访问情况会随网络环境变化。

**优惠码没有生效怎么办？** 检查输入是否正确，并查看结算页面的提示和最终金额。优惠码可能失效或不适用于所选订单；如果没有显示折扣，应按未优惠的价格重新判断是否购买，而不是预期之后一定会补上。

**续费、退款和迁移有哪些条件？** 这些事项可能影响实际持有成本和使用安排。付款前阅读当前订单及服务条款，尤其关注续费金额、退款适用条件和机房迁移限制；有不明确之处时先向服务商确认。这样即使套餐价格合适，也不会忽略后续管理所需承担的费用与责任。
